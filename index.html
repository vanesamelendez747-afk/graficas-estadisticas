1. Difusión de calor

Grafique el campo de direcciones para el modelo de difusión de calor según la Ley de Enfriamiento de Newton. Analice el comportamiento de las soluciones para valores de C desde −2 hasta 2.

dT/dt = −k(T − Tamb)

Donde T es la temperatura del cuerpo, Tamb es la temperatura ambiente y k es la constante de enfriamiento.

2. Flujo en tubería horizontal

Represente las líneas de flujo de la velocidad del fluido en una tubería horizontal utilizando la ecuación diferencial. Explore las soluciones para distintos valores de C.

dv/dx = −(f/2D) v|v|

Donde v es la velocidad, f es el coeficiente de fricción y D es el diámetro de la tubería.

3. Movimiento bajo fricción lineal

Grafique el campo de direcciones para el movimiento de una partícula con fricción lineal, usando la ecuación diferencial. Evalúe el comportamiento de las soluciones según distintos valores de C.

dv/dt = −bv + F

Donde v es la velocidad, b es la constante de fricción y F es una fuerza constante.

4. Crecimiento poblacional logístico

Represente el campo de trayectorias para el modelo de crecimiento poblacional logístico. Analice los comportamientos para C desde 0 hasta 6 millones de personas.

dN/dt = rN (1 − N/K)

Donde N es la población, r es la tasa de crecimiento y K es la capacidad máxima.
